Petunjuk Import ke Blender:

  1. Ekspor model sebagai file STL
  2. Buka Blender
  3. File > Import > STL
  4. Pilih file yang telah diekspor
  5. Untuk edit lebih lanjut:
    • Tekan Tab untuk masuk mode edit
    • Gunakan alat seperti Extrude, Bevel, dll.
